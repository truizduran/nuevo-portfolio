# Tomás Ruiz Durán — Portfolio

Sitio personal de una sola página, usado como portfolio para mostrar mis proyectos como desarrollador frontend.

🔗 **Demo en vivo:** https://tomasruizduran.netlify.app/

![Captura del sitio](./assets/screenshot.png)

## Sobre el proyecto

Portfolio personal construido desde cero, con estética estilo Apple: diseño limpio, tipografía grande, materiales translúcidos y animaciones físicas. Pensado para ir sumando proyectos nuevos fácilmente a medida que los voy terminando.

## Secciones

- **Hero** — presentación y frase de valor
- **Sobre mí** — mi historia como desarrollador
- **Habilidades** — HTML, CSS, JavaScript, Git, Bootstrap, Sass, Tailwind CSS
- **Proyectos** — fichas con contexto (problema → proceso → solución → resultado), tecnologías usadas, y links a demo y repo:
  - Comparador de precios de videojuegos (extensión de Chrome)
  - Web de fotografía para cliente externo
  - Fútbol en vivo — Liga Profesional Argentina (extensión de Chrome)
- **Contacto** — formulario, email y redes (GitHub, LinkedIn)

## Tecnologías

- HTML5
- CSS3 (sin frameworks — estilos propios)
- JavaScript vainilla

## Cómo correrlo localmente

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/truizduran/TU-REPO.git
   ```
2. Abrí `index.html` en tu navegador. No necesita instalación ni servidor.

## Cómo agregar un proyecto nuevo

Las tarjetas de proyecto están pensadas para sumarse fácil: agregá un nuevo objeto con título, descripción, tecnologías, link de demo y link de repo, y la tarjeta se genera sola.
